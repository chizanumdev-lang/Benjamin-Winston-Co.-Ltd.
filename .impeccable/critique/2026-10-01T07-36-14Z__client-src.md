## Design Specificity Verdict
Mostly a generic online-shop product grid (cream and terracotta, shadowed cards that lift on hover, pill buttons) with B&W's name on it. It goes against the "internal tool, not a storefront" principle. What fits B&W is the content: categories, codes, naira formatting. It doesn't support the counter-lookup job: prices can't be scanned in a column, units are faint, search fails on real phrases, no list date.
Automated checks: the command-line checker found 1 issue (overused font Inter, index.css:43). The in-browser scan logged 369 hits from 6 issues: tiny text on .product-category (285 hits, index.css:518), long uppercase labels (76, index.css:520), 5 contrast failures (#837f76 grey 3.6–4.0:1; Add button 3.8:1), a skipped heading level (h1 to card h3), and a cream-background warning.

## Priority Issues
- [P0] Multi-word search returns 0 results (server.js:74-76; "ansell flood", "twin and earth", "2.5mm twin" all 0). Fix: match each word separately; normalise units; add shop synonyms; rank exact code matches first. Command: harden
- [P1] Unit and price-list date nearly invisible when quoting (unit 11.5px at 3.99:1, index.css:556; three ways of wording units; no 1 Jun 2025 date; VAT note only in footer). Fix: show "₦180,000 / 100m reel"; highlight units that aren't "each"; always show the list date. Command: typeset + clarify
- [P1] Card grid makes scanning and comparing hard (index.css:494). Fix: compact table (Description · Code · Unit · Price) with right-aligned, lined-up prices; category headings that stay visible; stacked rows on narrow screens. Command: layout + distill
- [P1] Too slow by keyboard; Add form isn't a proper dialog (no autofocus or / shortcut; no type-to-jump; screen readers don't hear the highlighted option; focus escapes the form and isn't returned; Esc closes the whole form via AddProductModal.jsx:23; duplicate id). Command: harden
- [P2] Empty, error and admin states not designed (dead-end empty state; offers to create a category that exists; no confirmation after adding; custom items unmarked; "Add item" is the loudest button). Command: clarify + quieter
