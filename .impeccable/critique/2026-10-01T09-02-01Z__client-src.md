## Design Specificity Verdict
Clearly built for this shop: search understands shop phrases, unit wording is consistent, kobo is kept, the list date and fittings-without-lamps note are always shown, the / shortcut, prices in one column. Template remnants: cream and terracotta colours, rounded corners, pill tags. Automated checks: command-line checker clean; in-browser scan 1 hit (cream background, index.css:4, a matter of taste).

## Priority Issues
- [P1] Sizes not in numeric order (server.js:90-96, search.js:139). Fix: compare numbers inside names as numbers. Command: clarify
- [P1] A new search keeps the old scroll position, so the first results and the note are hidden under the toolbar (App.jsx:78-98). Fix: scroll to the top of the results when search, category or sort changes. Command: harden
- [P1] The "closest matches" note can show empty quotes and lists 49 loose rows (search.js:155, App.jsx:160). Fix: fallback wording; put items matching more words first and cap the list. Command: clarify
- [P1] Input borders 1.29:1 / 1.19:1, below the 3:1 accessibility minimum for control outlines (index.css:9, 37). Fix: darker border colour for inputs only. Command: polish
- [P2] Error and empty states and the Add form: old count shown on error, developer-facing copy, no shop guidance when nothing matches, ₦0 accepted, errors not announced, a filled form discarded on Esc or click outside, preview shows the raw unit. Command: harden
